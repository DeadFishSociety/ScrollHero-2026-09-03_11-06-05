# ScrollHero

## Set-up for dev environment

To set up this project on your development environment, open Unity Hub and click on `Add ˅` under the Projects tab. Then click on `Add from repository` and choose `GitHub` as the "Source control provider". Finally select this repository and then add the project. You can now open this project in Unity and the IDE of your choise.

## Manually build the project

To manually create a build for this project, go to `File > Build Profiles`, and just select the profile you want to build.
